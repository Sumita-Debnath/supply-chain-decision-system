# 🚚 Supply Chain Decision Intelligence System

## 📌 Problem Statement
Optimize inventory decisions across a multi-echelon supply chain under demand uncertainty while balancing cost, stockouts, and service level (SLA).

---

## 🎯 Objective
Minimize:

- Stockouts
- Total cost (holding + penalty)
while maintaining:
- SLA ≥ 95%

---

## 🏗️ System Design

- Monte Carlo demand simulation
- Inventory allocation policy
- Cost + SLA evaluation
- Pareto trade-off analysis
- Interactive Streamlit dashboard

---

## ⚙️ Key Features

✔ Multi-echelon inventory simulation  
✔ Stochastic demand modeling  
✔ Stockout + SLA KPI tracking  
✔ Cost optimization model  
✔ Pareto frontier analysis  
✔ Streamlit interactive dashboard  

---

## 📊 Business Metrics

- Stockout Reduction
- SLA Compliance (%)
- Total Cost
- Cost vs Service trade-off

---

## 📈 Key Insights

- Increasing inventory improves SLA but increases cost  
- Optimal policy exists on Pareto frontier  
- Demand volatility significantly impacts stockouts
